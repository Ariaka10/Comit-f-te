# Démo – Logiciel du comité des fêtes

Version de présentation, sans installation ni serveur.

## Lancer sous Windows
1. Télécharger `Comite-des-fetes-DEMO.html`.
2. Double-cliquer dessus : il s'ouvre dans Edge, Chrome ou Firefox.
3. Choisir un compte de démonstration (Administrateur, Élu·e, Membre, Visiteur).

Les données sont fictives et restent dans le navigateur de l'ordinateur.
Le lien « Remettre les données d'exemple » remet la démo à zéro.

## Modifier la démo
Éditer `app.fragment.html`, puis lancer `./build.sh` pour régénérer le fichier autonome.
